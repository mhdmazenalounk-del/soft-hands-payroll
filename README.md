# Soft Hands Payroll

Soft Hands Payroll is a Windows desktop application designed for U.S. home care agencies.

Features include payroll processing, caregiver and client management, scheduling, workforce management, reporting, and client billing.

## Current Version
Version 1.0.8

## Platform
Windows
